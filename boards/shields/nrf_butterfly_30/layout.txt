# nrf_butterfly_30 keyboard layout — source of truth for the keymap.
#
# Edit this file, then run generate-keymap.py in this same folder to
# regenerate nrf_butterfly_30.keymap. Do not hand-edit the .keymap file -- it
# gets overwritten.
#
# Each layer is a 3-row x 10-col grid, in the same left-to-right,
# top-to-bottom physical order you'd read the keyboard. The "|" is just a
# divider for readability -- the generator ignores it, so exact spacing
# doesn't matter.
#
# Layers are referred to by NAME (the [name] header), not by number. A
# layer's index (used internally for &mo/&tog/&to) is just its position in
# this file, top to bottom, starting at 0. Reordering layers in this file
# changes their index but every reference below uses the name, so nothing
# needs updating by hand.
#
# ZMK resolves a key from the highest-index *active* layer that isn't
# transparent there.
#
# Token reference:
#   A-Z, 0-9                    a letter or digit key
#   ESC TAB BSPC DEL ENTER SPACE      named keys
#   LSFT RSFT LCTL RCTL LALT LGUI     modifiers
#   COMMAND                           Mac Command key (alias for LGUI)
#   GRAVE MINUS EQUAL LBKT RBKT BSLH SEMI SQT COMMA DOT FSLH COLON   punctuation
#   TRNS                              transparent -- falls through to the
#                                      next active layer below this one
#   NONE                              key does nothing
#   MO<n>                             hold: momentary-activate layer index n
#   TOG<n>                            press: toggle layer index n on/off
#   TO<n>                             press: switch to layer index n only,
#                                      deactivating every other layer
#   BOOT                              reboot into bootloader (for reflashing)
#   BT0 BT1 BT2 BT3 BT4               select Bluetooth profile 0-4
#   OUTTOG                            toggle USB/BLE output
#   OUTUSB                            force keyboard output over USB
#   OUTBLE                            force keyboard output over Bluetooth
#   BTCLR                             clear current Bluetooth profile's bond
#
# Layer-reference tokens (by name, matching a [layer] header below):
#   <LayerName>                 alone: hold layer <LayerName> while held
#                                (momentary -- same idea as MO<n> but by name)
#   TOG<LayerName>               press: toggle layer <LayerName> on/off
#   TO<LayerName>                press: switch to layer <LayerName> only
#
# Hold-tap combo tokens: <base><Type><n>, e.g. "ZK1", "DL4", "SEMIL2".
# <base> is a normal key token (a letter, digit, or word token like SEMI).
# Tap the key for <base>; hold it (300ms+) with no other key pressed in that
# window and it acts as the "other side" below instead -- release after
# holding and nothing is typed, same as tapping a real modifier/layer key
# and letting go.
#   <base>L<n>    tap = <base>, hold = momentary layer "L<n>"
#   <base>T<n>    tap = <base>, hold = toggle layer "T<n>" on/off
#   <base>K<n>    tap = <base>, hold = the key aliased to K<n> (see "K<n> ="
#                  lines below a layer -- used for modifiers, e.g. K1 = LSFT)
#
# K<n> alias lines (only needed for K-type combos):
#   K<n> = <token>               defines what holding a "...K<n>" combo sends
